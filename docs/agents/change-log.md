# 検知の変更記録（消さない）

利用者の命令で作った、消えない記録。引き継ぎメモと違い、**件数で削らない・書き換えない・古い行を消さない。**
直すと別の箇所が悪化することを繰り返したため、変更1件ごとに「何を変えたか」「どう良くなったか」「何が悪くなったか」「戻し方」を残す。

## 規則

- 変更は1つずつ。1つの変更＝1つのPR（1つのマージコミット）にする。複数の直しを混ぜない。
- 取り込んだら、この表の一番下に1行足す。測る前は「効果」を「未測定」と書き、測ったら同じ行を追記で更新する（元の記述は消さず、`→` で続ける）。
- 効果の物差しは「口コミ記事（1844字）の誤り5点のうち何点に▶が付いたか」と「それまで拾えていたものを落としていないか」。件数の増減だけでは書かない。
- 自動の検査が通ることと、人が使って問題ないことは別（利用者の指摘）。本番に実際の記事を通し、▶と吹き出しを人の目で読める形で確かめるまで「直った」と書かない。
- 悪化したら、すぐ戻す: `git revert -m 1 <マージのコミット>` を1つのPRにして取り込む。戻したこともこの表に1行足す。

誤り5点: ①「口コミは広告以上」と断定 ②SIPSにSearchがあるように書く ③「第三者効果」の誤用 ④ネガティブ口コミの優位性を絶対視 ⑤ステマ規制を「対価を隠した場合だけ」と説明
