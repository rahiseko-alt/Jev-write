## 2026-09-23 北極星を決め、4工程を理想の向きへ直した。信頼度はJEVの1確率

**決めたこと**

- 目的は正誤を決めることではなく、確かめる必要のある箇所に信頼度を示して印を付けること。ブレの管理の道具である（ADR-0012）。
- 信頼度は JEV が返す1つの確率そのもの。表示は「信頼度〇〇%」だけ、80%以下にすべて▶（ADR-0011）。
- 北極星: 信頼度p%の文のp%が裏付けられ、同じ入力で値がほぼ揺れない（ADR-0013）。4工程（①取り出し ②探し方 ③選び方 ④JEVへの渡し方）はそれぞれ「手順・ガイドライン・禁止事項・向かう方向」を固定して直した（ADR-0014〜0017）。
- 生成LLMへの指示は3部構成（手順・ガイドライン・禁止事項）、出力形式は固定（flow-map）。
- 評価は、仕込んだ文が予測どおり低く出るかと、同じ記事を複数回流したときの揺れ幅で行う。「何個拾えたか」で数えない。
- 本番の配備は Vercel Pro（300秒）。費用を無駄にしない決まり（flow-map）。

**次にやること**

- 利用者の指示を待つ。候補は次の3つ（どれも北極星から見て逆向きが残っている箇所）。
- ③: 関連判定にかからず落ちる候補が平均168/186件ある。落とす順が出所名・URLの並びで決まっており、実質「上位だけ見る」になっている。
- ②: 検索語に主張自身の中身（例: SIPS の各要素の語）が入り、主張と同じことを書くページに寄っている。
- ①: 同じ文を1件にするか2件に割るかが回ごとに変わり、主張数と信頼度が揺れる。

**未解決の問題**

- E2（SIPS の Identify を Interest と書いた文）は、提唱者の note を含め Identify と書くページが資料にあるのに、信頼度92〜96%と高い。
- JEV の較正（p%がp%当たるか）を数値で示した公開資料は無い。自前で測るには正解付きの文が数百件要る。
- 私の環境のブラウザは本番の応答を30秒前後で待てずに切れることがある。本番の確認は API に直接送るか、利用者のブラウザで行う。

## 2026-09-23 資料0件でJEVに聞いていた主張を無くした。▶は17件→9件に減った
