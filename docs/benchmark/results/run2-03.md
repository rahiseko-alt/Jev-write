> 1ブロック目で止まりました。解析ジョブの実行に失敗しました。 / Anthropic API error (400 Bad Request): {"type":"error","error":{"type":"invalid_request_error","message":"Your credit balance is too low to access the Anthropic API. 判定を行うサービスの利用残高が足りず、結果は1件も出なかった。記事の中身の良し悪しを測る以前に止まっている。
ブラウザの開発者向け記録には、ほかに「404 (Not Found)」と「500 (Internal Server Error)」の読み込み失敗が1件ずつ出ていた（どの通信かは画面からは分からない）。
