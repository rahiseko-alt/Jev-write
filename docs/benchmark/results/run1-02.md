## 4. 人として使って困った点

1. **失敗の理由が英語の生データで出る。** 「Anthropic API error (400 Bad Request): {"type":"error",...}」は書き手には読めない。「いまは道具側の都合で検査できません。書き手の側で直すことはありません」のような日本語が必要。
2. **待てば直るのか、二度と動かないのかが分からない。** 再実行を促す文言も、問い合わせ先も無い。「チェックする」ボタンは青く押せる状態に戻るので、押し直せば直ると誤解して何度も押してしまう（実際に押し直しても同じ失敗だった）。
3. **「1ブロック目で止まりました」の意味が分からない。** 文字数の横に「（3ブロックに分けて順番に処理します）」と出るが、ブロックが本文のどこからどこまでか示されない。2・3ブロック目は試されたのかも分からない。
4. **入力欄の説明に「\n」がそのまま表示されている。** 最初の画面の薄い字が「ここに原文を貼り付ける\n事実の正確さ、…」となっていて、改行記号が文字として見えている（`00-start.png`）。
5. **説明文に「AIっぽい表現」をチェックすると書いてある。** 最初の画面の薄い字に「事実の正確さ、AIっぽい表現、根拠の有無をチェックし」とある。この機能は撤回済みと聞いているので、書き手に期待させる説明が残っている。
6. **最初の画面で文字が重なって見える。** 入力欄の上部の薄い説明文と、中央の「ここに原文を貼り付ける／または入力してください」が同時に出ていて、同じ案内が2回ある（`00-start.png`）。
