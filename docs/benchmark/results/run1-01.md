## 4. 人として使って困った点

1. **エラーが英語の生の文字列で出る。** 書き手には「Anthropic API」「credit balance」が何か分からず、自分の文章が悪いのか、待てば直るのか、誰に連絡すればよいのかが分からない。「いまは検査できません。時間をおいても直らなければ管理者へ」のような日本語の案内が欲しい。
2. **「1ブロック目で止まりました」だけでは次の行動が分からない。** 押し直せばよいのかも書かれていない。ボタンは押せる状態に戻っていたが、押し直して直るかは分からない。
3. **入力欄の案内文が崩れている。** 貼る前の画面で、上の案内文に「\n」という記号がそのまま出ており（「ここに原文を貼り付ける\n事実の正確さ、…」）、さらに中央の「ここに原文を貼り付ける／または入力してください」と二重に表示されている（00-top.png）。（なお、画面の部品が読み込めなかった1回目では、貼った本文の上に中央の案内文とアイコンが重なって透けて見えた。読み込めた2回目では重なりは無かった。）
4. **案内文に「AIっぽい表現」をチェックすると書いてある。** 引き継ぎメモではAI表現の検出は撤回済みとされており、書き手に期待させる内容と実際がずれている可能性がある【曖昧】（今回は検査が完了せず、実際に出るかは確認できなかった）。
5. （道具ではなく測定環境の問題）この作業環境のブラウザは、本番の画面を読み込む通信が途中で失敗することがあった（net::ERR_TOO_MANY_RETRIES）。1回目は画面の部品が読み込まれず、貼っても文字数が0のまま「チェックする」が押せなかった（この時の画像は2回目で上書きされ、残っていない）。2回目は通信をPlaywright側から再送する方法で読み込み、上記のエラーまで進んだ。
