## 4. 人として使って困った点

- **止まった理由が英語の生の文字列で出る。** 「Anthropic API error (400 Bad Request): {"type":"error",…}」という機械向けの文言がそのまま出る。非エンジニアの書き手には、自分の文章が悪いのか、道具が壊れているのか、待てば直るのかが分からない。
- **次に何をすればよいかが書かれていない。** 「1ブロック目で止まりました」とあるだけで、「時間をおいて再度お試しください」「運営に連絡してください」などの案内が無い。押し直しても同じ結果だった。
- 開いた直後の入力欄の薄い説明文に「ここに原文を貼り付ける\n事実の正確さ…」と、改行のつもりの「\n」が文字のまま見えている（`00-top.png`）。
- **貼った本文は消えずに残っていた**ので、押し直す手間は小さかった（良かった点）。
- 入力欄の説明に「事実の正確さ、AIっぽい表現、根拠の有無をチェックし」とある。引き継ぎメモではAI表現の検出は撤回済みとされており、画面の説明と食い違っている【曖昧】（道具の中身は見ていないので、実際に何を検査するかは確かめられていない）。
