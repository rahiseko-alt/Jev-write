# JEVには、関連するとJEV自身が判定した節だけを渡す（北極星④を向き直す）

## Context

ADR-0013 の北極星④は「JEVへは該当する節だけを渡す（無関係な材料が増えると精度が落ちる）。長い資料を丸ごと渡すのは逆向き」。
ところが #72 以降、信頼度の Noul「記事の原文のこの文（claim.original）は、sources の内容で裏付けられているか」には、
集めたページの本文を全文、記事全体と一緒に渡していた（32kトークンを超える分は分割）。
同じ記事・同じ文で信頼度が 84% と 68% に揺れた（ADR-0012 が直すべき問題とした揺れ）。

JEV公式（2026-09-23 に確認）:

- model-jaggedness「Large state full of irrelevant detail」: 判定に無関係な内容で state が大きくなるほど精度が落ちる。
  先に絞り、問いに要るものだけを送る。コードで絞れないときは Noul で関連を判定して絞る（classifying_rag_passages を参照）。
- cookbooks/classifying_rag_passages: 資料を1件ずつ Noul（`is_relevant`）で判定し、閾値はコードで持つ。関連の下限は 0.45
  （「出発点であって既定値ではない」）。
- cookbooks/citation_check: 資料を節（270〜3,122字）に分け、主張と照合するのはその節だけ。
- patterns/fan-out: 1つの state に多くの問いを載せて1回で問い、どれを使うかはコードが決める。

## Decision

- **ページ本文を節に分ける。** 見出し（■・【・# で始まる行、句読点で終わらない短い行）と段落（行）の区切りで分け、
  1節はおおむね 270〜3,122字（citation_check の節の大きさ）。見出しでの区切りは節が 270字に達してから。
  3,122字を超える段落は文末で、文末の無い塊はその長さで区切る。**節の文字は削らない**
  （節をつなぎ直すと本文に戻る）。ファクトチェックの評価も1件1節として同じに扱う。
- **1回目: 関連を JEV に問う。** 文ごとに、その文の全節を state に入れ、節ごとに Noul を1問ずつ、1回のリクエストで問う
  （fan-out。1問1判断）:「sources[i] のこの節は、claim.original と同じ事柄について述べているか」。はい＝関連あり。
  どの節も問う（ADR-0007: こちらの判断で候補を捨てない。捨てるかどうかは JEV の答えで決まる）。
  入力上限（状態＋最長の問い 32k、全体 64k）を超えるときだけ、節を削らずに複数のリクエストに分ける。
- **2回目: 信頼度を問う。** 関連の確率が線（`RELEVANCE_THRESHOLD`、既定 0.45＝公式 cookbook の `relevant_min`、
  `JEV_RELEVANCE_THRESHOLD` で変更可）以上の節だけを、ページの順・節の順のまま `sources` に入れ、ADR-0011 と同じ文面の
  信頼度の Noul を問う。関連する節が1つも無ければ `sources` は空で同じ問いを立てる（資料0件と同じ扱い）。
- **記事全体は、どちらの問いにも渡さない。** 2つの問いはどちらも claim.original と sources の関係だけを問い、記事の残りを
  参照しない。公式の言う「問いに要らない材料」にあたる。さらに記事にはその文自身が含まれるため、記事を渡すと
  「文が記事に書いてある」ことが裏付けに読まれうる（ADR-0008 で、自分自身に照らす問いが捏造ほど高く出た件と同じ形）。
  ADR-0011 の「記事全体…を1回の問いにまとめて渡す」は、この決定で置き換える。文だけで意味が通らない問題は、
  ①主張の取り出し側で扱う。
- **表示は変えない。** 信頼度の表示、80%の線、吹き出しにページを並べることは ADR-0011 のまま。吹き出しに並ぶページは、
  関連ありと判定された節を含むページにする（ファクトチェックの評価も同じ）。
- ページごとの関係を問う Choice（supports／contradicts／says_nothing）は廃止する。ページを並べる選択は関連の Noul が担い、
  画面は信頼度しか出さない（ADR-0009・0011）。これに伴い、ウェブ資料からの集計用の verdict は付けない。

## Consequences

- 北極星④が「逆向き」から「理想の向き」に変わる。信頼度の問いの state が小さくなり、無関係な材料による揺れが減る見込み
  （未測定。ADR-0012 の物差しで、同じ記事を複数回流して揺れ幅を測る）。
- JEVの呼び出しは、文ごとに「関連 1回（上限超えのときだけ数回）＋信頼度 1回」になる。これまでの文ごと約1回から増える。
  資料が0件の文は信頼度の1回だけ。
- 関連の線は測りながら動かす。関連ありを取りこぼすと、信頼度は資料0件と同じ扱いで低く出る。
- 1回目は、1つの state に全節を並べて節ごとに問う（fan-out）。公式 cookbook は資料1件につき1リクエストだが、
  ここでは ADR-0007（まとめられる問いは分けない）を優先した。関連の判定が揺れる場合、最初に疑うのはこの点である。
