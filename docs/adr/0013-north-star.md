# 北極星: 信頼度p%の文のp%が裏付けられ、同じ入力で値がほぼ揺れない

## Context

利用者の指示はこうである。

> 先に理想形を北極星として決めよう。決して届かないけど目指すべきものだよな、方向性とその高さまで目指す。
> 目指すだけだからそこに到達未到達で右往左往はしない、しかし、逆を向いている、届かないなりに改善していないのは問題だ。

信頼度を左右する工程は決まっている: 主張の取り出し、資料の探し方、資料の選び方、JEVへの渡し方。
それぞれの理想形を、研究とプロのファクトチェックの手順、JEV公式から探した（2026-09-23、補助役3体の調査）。

## Decision

**全体の北極星:** 信頼度p%と出た文の、実際にp%が渡した資料で裏付けられている（較正）。
同じ記事を何度流しても、値は±1%ほどしか揺れず、80%の線をまたがない（再現性。手本は TypeSafe の実測で
同一入力15回の標準偏差 0.0102）。

到達したかどうかで右往左往しない。判断するのは、各変更がこの方向を向いているか、逆を向いていないかである。

| 工程 | 理想の向き | 逆向き（やってはいけない） |
| --- | --- | --- |
| ①主張の取り出し | 1つの事実だけ・それだけで意味が通る（代名詞を実体に置き換える）・限定語（すべて・必ず・条件）を残す・原文が真なら主張も真（Claimify, VeriScore, SAFE） | 限定語を落とす、細かく割りすぎる、意見や推測を事実に混ぜる、曖昧な文に解釈を1つ決め打ちする |
| ②資料の探し方 | 主張ごとに「確かめるための問い」を作って検索し、結果を見て作り直す。一次資料と反証も探す。最初のサイトから離れて出所を調べる（SAFE, AVeriTeC 上位手法, lateral reading, SIFT） | 主張の文をそのまま検索する、上位の結果だけを見る、主張より後の資料を使う |
| ③資料の選び方 | 一次資料（データ表・法令文書）優先、主要な点は独立した複数の出所、1件ごとに関連・使えるか・矛盾を判定し、矛盾は捨てず別枠に残す（IFCN, JEV cookbook classifying_rag_passages） | 同じ出所の転載を別々の裏付けと数える、矛盾を黙って捨てる、二次要約で済ませる |
| ④JEVへの渡し方 | 該当する節だけを渡す（無関係な材料が増えると精度が落ちる。JEV公式）。指示文・資料の順番・モデルの版を固定する | 長い資料を丸ごと渡す |

**測り方:** 正解付きの文（人が「資料で裏付けられているか」を付けたもの）で、信頼度の区間ごとに
実際の裏付け率を比べる（信頼度図）。同じ記事を複数回流し、揺れ幅と80%の線をまたいだ割合を見る。
回数は費用の決まりに従い最小限にする。

## 2026-09-23 時点の向き

- ①: 未確認（言い換えは LLM 任せ）。
- ②: 逆向き（記事全体で検索語6本のみ、主張ごとの検索は候補0件のときだけ）。
- ③: 一部逆向き（主語の語の出現回数で選ぶ、一次性・独立性を見ていない）。
- ④: 逆向き（#72 でページ全文を渡すようにした）。
