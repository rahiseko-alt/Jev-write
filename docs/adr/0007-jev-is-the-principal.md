# JEVが主役。仕様はJEV公式に従い、JEVの邪魔をしない

## Context

この製品の判定はJEVが行う。にもかかわらず実装は、JEVの手前で候補を削り、JEVが返した数値を捨て、
1回で済む問いを分けて投げていた。結果として、見逃しも誤検知もJEVではなくこちらのコードが作った。

## Decision

- **JEVが主役である。** 判定はJEVが行う。こちらのコードは、JEVに渡すものを揃え、返ってきたものを
  そのまま扱う役に徹する。
- **仕様はJEV公式を一次情報とする。** 実装前に公式仕様を読む。
  - API仕様: `https://api.typesafe.ai/openapi.json`
  - 文書: `https://docs.typesafe.ai`
  この置き場所にある要約や、担当者（人間・AIを問わない）の記憶を一次情報としない。仕様は変わる。
- **JEVの性能を邪魔しない。** 具体的には、次をしない。
  1. JEVに聞く前に、こちらの判断で候補を捨てない。
  2. JEVが返した数値を捨てない。返ってきた確率と確信度は、判定の強さとしてそのまま使う。
  3. 1回のリクエストにまとめられる問いを、分けて投げない。
  4. JEVが答えられる問いを、こちらの文字列処理で代替しない。

## Consequences

- 判定の質に不満が出たとき、最初に疑うのはこちらの渡し方と受け取り方であって、JEVではない
  （ADR-0006 の層の順序と同じ。層4を疑う前に層2が白であることを示す）。
- 公式仕様が変わった場合、この置き場所の実装が追随する。逆はない。
