# 信頼度は、JEVが返す1つの確率である。80%以下にはすべて▶を付ける

## Context

画面の数値は、中身の違う3つの数値が混ざっていた（資料と一致する確からしさ、資料と食い違う確からしさ、
記事の残りとの辻褄）。記事01では、正しい文の「77%」も、仕込んだ箇所の「16%」も辻褄の数値だった。
あわせて「資料と食い違い」「裏付けなし」「資料と一致」の3つの札を出しており、数値と役割が重なっていた。

利用者の指示はこうである。

> 正しい、誤った、という概念は存在しない。数値で示しているだろ
> 信頼度〇〇%だけ。信頼度80%以下のところには全てつける。何をもって何%かはこっちで決めないといけない

## Decision

- **信頼度は、JEVが返す1つの確率そのものである。** 文ごとに JEV へ Noul で1問だけ問う:
  「記事の原文のこの文（claim.original）は、sources の内容で裏付けられているか」。
  返ってきた確率を、こちらで加工せずに「信頼度〇〇%」として表示する（ADR-0008: 数値はJEVが返したものだけ）。
- **渡すものは絞らない（ADR-0007）。** 記事の原文の文そのもの（言い換えではない）、記事全体、
  集めたページの本文をすべて、1回の問いにまとめて渡す。資料が1件も無い文も同じ問いを立てる。
- **1つの問いに判断は1つだけ**（JEV公式の禁止事項: 複数の判断を1問に詰め込まない）。
- **表示は「信頼度〇〇%」の1つだけ。** 「資料と食い違い／裏付けなし／資料と一致」の札は使わない。
  正しい・誤りという言葉も使わない（ADR-0009）。
- **信頼度80%以下の文には、すべて▶を付ける**（利用者の指定）。線は1か所の設定値にする。
- 根拠のページは、これまでどおり吹き出しに並べる。

## Consequences

- 画面の数値の意味が1つになる。低いほど「渡した資料では裏付けられていない」ことを示す。
- 資料が集まらない文は低い数値になり、▶が付く。資料集めの質（ADR-0008: 材料を揃えるのはこちらの責任）が
  そのまま数値に出る。
- 80%の線は、本番で測りながら見直す対象である。
