# 正誤を宣告しない。資料との関係を述べる

## Context

この道具は、どの文がどれだけ裏付けられているかを数値で示し、人が見る場所を決めるためのものである
（ADR-0008）。にもかかわらず画面は、資料に食い違いがあるだけで **「事実の誤り」** と表示し、
修正案を既定で本文に適用していた。

実際に何が起きたか。名古屋の施設を扱う記事で「国際センター駅から徒歩3分」「名古屋駅から徒歩8分」が
「誤り」と断定された。どちらも公式サイトに載っている正しい記述で、たまたま拾われた別施設の掲載ページが
違う数字を書いていただけだった。断定した結果、正しい文が赤く塗られ、書き換え案が既定で採用されていた。

利用者の指摘はこうである。「誤りと、断定した、の意味が分からない。なぜ断定という結果を出すんだ？」

実際に分かっているのは「あるページが違うことを書いている」という事実だけであり、どちらが正しいかは
この道具には分からない。「誤り」と名付けた瞬間、断定口調で嘘をつくLLMと同じ失敗をする。

## Decision

- **判定の札は、真偽ではなく資料との関係を述べる。**
  - 食い違うページがある → **「資料と食い違い」**（「事実の誤り」とは言わない）
  - 裏付けるページがある → **「資料と一致」**（「確認済み」「事実の正しさが確認されています」とは言わない）
  - どちらも無い → **「裏付けなし」**（誤りという意味ではないと明記する）
- **事実の修正案は提案にとどめ、既定では採用しない。** 利用者が選んで初めて本文に入る。
  文章表現（AIっぽい言い回し）の修正は事実に関わらないので、従来どおり既定で採用する。
- **説明文で、この道具に何が分かって何が分からないかを言う。** 「どちらが正しいかは、この道具では
  決められません。根拠のページを見て判断してください」と書く。

## Consequences

- 「誤り」という語は画面から消える。件数を「何件検知したか」で数えることも、もう意味を持たない。
  評価の軸は、裏付けの強さの数値が、確かめる値打ちのある文を上に並べられているかである。
- 修正案が既定で入らないため、利用者が何も選ばなければ本文は原文のまま出る。これは意図した動作であり、
  「直っていない」ではなく「まだ選ばれていない」である。
