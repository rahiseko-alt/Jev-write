# 書き換えない。裏付けの弱い箇所を知らせるだけ

## Context

この道具は、どの文がどれだけ裏付けられているかを数値で示し、人が見る場所を決めるためのものである
（ADR-0008、ADR-0009）。にもかかわらず実装は、生成側に文章を書き換えさせ、書き換え後の文を
差分で見せ、採否を選ばせる作りを抱えたままだった。

利用者の指示はこうである。

> ていうか、もう一切書き換えなくていいよ。信頼度の低いところを検知して知らせろよ

書き換えを残すかぎり、「どこを直すか」を道具が決めることになる。裏付けの数値を出して人に渡す、
という値打ちと噛み合わない。

## Decision

- **文章を書き換えない。** 生成側への書き換え依頼（rewrite）、書き換え後の差分検査（Delta Check）、
  局所修正（surgical fix）、訂正文の作成（correction）を、すべてこの置き場所から削除した。
- **画面は一つ。** 書かれた文章に印を付けて見せる。原文／修正版／左右比較／インライン差分の
  切り替えは無くなった。比べるものが無いからである。
- **採否の操作も無い。** 採用・元に戻すは、書き換えがあって初めて意味を持つ。
- 出すのは、**裏付けの強さの数値、印、根拠のページ**の3つだけ。どう直すかは書き手が決める。

## Consequences

- 1回の処理から、生成の呼び出しが1つとJEVの呼び出し（差分検査）が減る。速く、安くなる。
- 「修正版」という言葉が画面から消える。全文コピーは、書かれた文章をそのまま写す。
- 文体の指摘（AIっぽい言い回し）は、検知して知らせるだけで、直さない。
