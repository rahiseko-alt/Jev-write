# 日付と数値は、JEVに選ばせてコードで比べる

## Context

本番で、記事の文「…告示が指定され、2024年10月1日から施行されています。」（正しくは2023年10月1日）に対し、
消費者庁の公式ページを含む7ページすべてで JEV が「支持する」と答え、信頼度88%で▶が付かなかった。

JEV公式（`https://docs.typesafe.ai/model-jaggedness/jev-1.13`）は、日付の比較・数を数える・計算を苦手として挙げ、
「値の取り出しは選ばせ、比較・計算はコードで」と定めている。値の候補は正規表現か生成モデルで作り、
JEVには候補から選ばせる（`https://docs.typesafe.ai/cookbooks/pre_parsed_value_extraction_cookbook`）。

## Decision

- **役割を分ける。**
  - コード: 文（claim.original）に書かれた日付・数値を正規表現で取り出す。各ページ本文から同種の値の候補を取り出す
    （西暦・和暦・全角数字・漢数字・年のない「10月1日」・15,000円／1万5000円・割と%）。
  - JEV: ページごとに Choice で「sources[i] の本文で、その同じ事柄について書かれている日付（数値）はどれか」を選ぶ。
    選択肢は候補の文字列そのものと `none`。支持の問いと同じリクエストに載せる（ADR-0007）。
  - コード: 選ばれた値と文の値を、両方に書かれている部分（年・月・日、単位が同じ数）で比べる。
- **信頼度は変えない（ADR-0011）。** 表示する数値は JEV が返した支持の確率のまま。こちらで数値を作らない。
- **食い違いがあれば▶を付ける。** JEV の選択の確信度（JEV が返した値）が 0.5 以上（ADR-0008 の「要確認」以上）で、
  コードの比較で値が違うとき、信頼度に関わらず▶を付ける。80%以下の文にはこれまでどおりすべて▶が付く。
- **吹き出しに、ページが書いている値とそのページを出す。** 「資料では 令和5年10月1日（文中は 2024年10月1日）」。
  正しい・誤りとは言わない（ADR-0009）。どちらが正しいかは読み手が資料で確かめる。
- 検索は変えない。検査中の数字で検索しない（#31）。

## Consequences

- ▶の付いた文に、80%を超える信頼度が並ぶことがある。▶の理由は吹き出しの「資料では」の行で分かる。
- 片方にしか年が無い日付、単位の違う数は比べない（食い違いにしない）。見逃し側に倒している。
- 候補が 254 を超えるページは、JEV の選択肢の上限により先頭 254 件だけを候補にする。
